Evidence rules

The report shows where knowledge stops.

AgentGate is designed around evidence boundaries rather than optimistic defaults.

01

Required checks must finish

A result can be clean only when every required check completed. A skipped or crashed check remains incomplete.

02

Unmeasured stays unmeasured

Unavailable manifests, registry metadata, packages, or private configuration are visible gaps—not implied approvals.

03

History cannot be reconstructed

Retained snapshots make evidence changes visible. If no comparable snapshot exists, the report says so.
