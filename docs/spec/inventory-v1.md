# 我的工具清单与证据报告

这条流程回答“这份清单能对应到哪些已采集材料，还缺什么”，不回答“我的机器已经安全”。
它不扫描本机，不启动 MCP server，不安装包，也不访问清单中的地址。

## 页面入口

运行 `node bin/agentgate.mjs serve`，打开它打印的本地地址下的 `/inventory.html`。
静态站点构建也会生成同名页面，并携带构建时的索引快照及相同匹配逻辑。

1. 粘贴名称清单，或手动选择 `.txt` / `.json` 文件。
2. 模糊或多义的名称需要本人确认候选；没有匹配项的条目不会被丢弃。
3. 填写自己实际使用的版本。选择目录候选不等于确认实际版本，页面不会替你填写。
4. 查看缺口、已有发现和下一步建议，下载可独立打开、可打印的 HTML 报告。

页面只在浏览器内存中处理这份清单，不上传、不写入浏览器存储；刷新或重置会清除输入。
下载是用户主动保留报告，报告包含工具清单，转交前应检查是否有内部工具名称等敏感信息。
网站及资源访问可能产生常规服务访问日志，但不会发送输入清单或按名称发出查询请求。

## 输入

最多 500 条、文件或文本最多 1 MB。纯文本每行一个名称；精确输入推荐 JSON：

```json
{
  "tools": [
    {
      "name": "我的文件工具",
      "server": "example/files",
      "package": "@example/files",
      "registry": "npm",
      "version": "1.2.3"
    },
    { "name": "还没有确认版本的工具", "package": "some-tool" },
    "an-unknown-tool"
  ]
}
```

顶层也可以直接是数组。条目只接受 `name`、`server`、`package`、`registry`、`version`。
省略 `name` 时可从 `server` 或 `package` 补显示名称。不要导入带 `env`、令牌、命令参数的
完整客户端配置，其他字段和结构会被拒绝；本功能不需要任何凭据。

## 状态

| 状态 | 含义与下一步 |
| --- | --- |
| `unmatched` | 当前索引没有对应项；核实标识或补材料，不能推断工具不存在或不安全 |
| `ambiguous` | 存在多个候选，或仅是模糊名称；在页面选择、或在 JSON 提供精确身份 |
| `version_missing` | 未提供实际精确版本；补版本，不采用目录版本作为默认值 |
| `version_mismatch` | 清单版本与可用资料不一致；需要相应版本的材料 |
| `insufficient` | 历史样本、未测量、缺来源/内容指纹、无包或数据冲突等；补资料 |
| `matched` | 身份、用户填写版本和已列材料能够对应；不表示没有发现，不表示安全认证 |

报告同时保留已测范围、发现、无法测量部分、来源时间及内容指纹。
指纹只能绑定索引记录中声明的已测材料，不能证明材料发布方可信，也不能证明用户本机
安装的是这些字节；没有新扫描，没有覆盖未列出的传递依赖、整个包或运行时行为。
公共资料不是内部环境评估，也不是第三方安全背书。

随仓库提供的索引是历史样本，即使名称版本一致，也不会产生确认匹配。
若静态构建截断了目录，页面与报告会保留总量/截断提示；未匹配仅限本页可用记录。
索引日期应由使用者结合实际环境判断是否足够新，本功能不自行承诺有效期。

## 命令行

```sh
node bin/agentgate.mjs inventory --input examples/inventory/tools.json --out my-tools.html
node bin/agentgate.mjs inventory --input tools.json --index data/index.json --format json
```

`--index` 显式指定时不会回退到其他索引。未指定时沿用 CLI 的本地索引/样本发现方式。
输出默认 HTML，也可选 JSON；JSON 带 `schemaVersion: 1`、输入清单、匹配结果和报告/索引时间。
无 `--out` 时输出到终端；指定时只新建文件，不覆盖旧报告、输入或索引。
报告生成成功退出 0，输入/文件/数据错误退出 2；退出 0 **不是**策略放行。
自动化阻断仍应使用原有的 `check` 命令。

## 本轮范围

没有加入账号、云端保存、客户通知、持续监控、升级审批或实际工具执行。
本地可用不等于已经发布；真实用户采用、报告转交和付费意愿还需要单独验证。
