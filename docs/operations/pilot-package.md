# 免费证据体检 · 试点方案

*给潜在设计伙伴的一页说明。可以直接发出去;下面每个承诺都能在仓库里验证。*

## 一句话

**四周,免费。** 我们用 agentgate 扫你们指定的仓库,交给你们一份带证据的报告,再加上一份能在你们 CI 里生效的策略。我们只换一次一小时复盘。

## 你们会拿到什么

| # | 交付物 | 形态 |
| --- | --- | --- |
| 1 | **证据报告** | 一个 HTML 文件,可直接转发给安全或合规同事。里面写清楚查了什么、**没查到什么**(单列一节)、以及每条发现的位置与原因 |
| 2 | **策略文件** | 一份 `agentgate.policy.json`。你们写规则,我们负责让它在你们的 CI 里真的卡住不合规的工具 |
| 3 | **静默变更说明** | 一次历史对比:过去几周里,哪些东西在版本号没动的情况下发生了变化 |
| 4 | **一小时复盘** | 我们逐条讲发现,你们决定改哪些、哪些是我们误报 |

样例报告(拿一个故意违规的项目生成的):<https://ciceroyang.github.io/agentgate/report-sample.html>

## 时间线

| 周 | 做什么 | 需要你们 |
| --- | --- | --- |
| 第 1 周 | 接上仓库,跑第一遍,出初版报告 | 只读的仓库访问 + 一个联系人 |
| 第 2 周 | 一起写策略文件,接进 CI | 半小时,确认规则 |
| 第 3 周 | 观察一周,出历史对比 | 无 |
| 第 4 周 | 复盘,交付终版报告 | 一小时 |

## 我们需要的(三件)

1. **只读的仓库访问**,或一份允许我们 `git clone` 的仓库清单;
2. **一个联系人**(最好来自平台工程或安全团队,而不是采购);
3. **一小时**(第 2 周半小时,第 4 周半小时多一点)。

## 我们不做的

- **不碰生产系统。** 只读源码与公开资料,不连你们的服务、不装任何包、不执行任何东西。
- **不要凭据。** 不要密钥、不要 token、不要数据库连接串。
- **不收钱。** 试点期间没有费用,也不需要采购流程;结束后如果你们不继续,直接把报告留着就行。
- **不公开点名。** 结果默认只在你们和我们之间;**能不能引用、怎么引用,由你们决定**,匿名也可以。

## 为什么我们这么做

我们要找的是三种东西:**真实环境里才会出现的问题**、**你们对"这份报告有没有用"的判断**、以及**如果收费你们会不会买**。这三样东西我坐在自己电脑前编不出来。

## 如果试点有用,后面是什么

开源内核是免费的、可以永久自托管。付费部分是企业要交账时才需要的东西:SSO/SAML、RBAC、多租户、不限留存、签名审计导出、SIEM 对接。Team 版本 ¥29,800/年,Enterprise ¥158,000/年起——**但这一页不推销,第 4 周复盘时我只会问一句"如果这个价,你会买吗,预算在哪"。**

## 一个诚实的提醒

这个工具很年轻,只有我一个人在用。所以试点里**你们大概率会遇到误报**,也可能遇到我们没覆盖到的东西。遇到就直说——我们更想知道哪里不对,而不是收到一句"还行"。

## 对方要交出什么:一份阶梯,默认从第 0 层开始

**绝不要一上来就要仓库。** 没有人会把代码库给一个陌生人和一家新公司——要求这个,等于把转化率钉在零。
真正需要的东西按"对方要承担多少风险"排成四层,默认只走第 0 层:

| 层 | 对方要给的 | 我们能出什么 | 风险 |
| --- | --- | --- | --- |
| **0(默认)** | **一份清单:在用的 MCP server / agent 工具的名字** | 用已有索引逐个查:每个工具的注册表、包、仓库证据;查不到的明确写 unmeasured | 零。一句话就能答应 |
| 1 | 导出 `.mcp.json`(去掉内部地址和 key) | 针对他们配置的报告:哪些未固定版本、哪些传输层无认证 | 低 |
| 2 | **他们自己跑开源扫描器**,把输出发我们 | 我们把输出写成正式报告。**代码不出他们的机器** | 低:代码不用给 |
| 3 | 只读私库 | 完整检查 | 高。**只有前面都跑过、他们信我们了才可能** |

第 0 层之所以是默认,不是因为它弱,而是因为:

1. **零风险**——对方只要回答"我们用了哪些",没有理由拒绝;
2. **我们立刻能出东西**——索引里已经有 2,000+ 条记录,不需要等他们做任何事;
3. **报告本身就是下一步的推销**——他看完要么说"这东西对",要么说"我们没这问题"。

第 2 层是最强的承诺,值得直接写在对外话术里:**开源的部分你自己跑,代码不出你的机器。**
