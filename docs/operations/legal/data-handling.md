# 数据处理说明(草稿)

> **这是草稿,不是法律意见。** 事实部分我逐条验过(下面标了怎么验),但发布前请让律师或合规模板过一遍,尤其是你要面向企业客户。标注「需要你补」的地方只有你能填。

## 一句话

跑在你机器上的工具**不联网**;我们自己的服务**只存公开数据**;站点**不收集任何东西**。

## 一、`agentgate check` 和 `agentgate serve`:不发起任何对外请求

这两个命令读本地文件、只监听本地端口,不向任何地方发送数据。这不是声明,是测试:`test/no-telemetry.test.mjs` 会把 `fetch`、DNS 域名解析、以及所有非回环的 socket 连接标记为失败,再跑这两个命令,并断言结果与联网时完全一致。同一套拦截器用在采集脚本上会立刻报错——这是阳性对照,证明拦截器真的拦得住。

回环地址(127.0.0.1)是允许的:监听端口本来就要解析绑定地址,而连回环不是连"外面"。

## 二、npm 包:安装它不会执行任何代码

- **零运行时依赖**(`dependencies` 为空)。
- **没有任何安装期脚本**:`preinstall` / `install` / `postinstall` / `prepare` 全都没有。所以 `npm install` 不会运行这个包里的任何东西。
- 包内没有原生构建(binding.gyp 之类)。
- 104 个文件,主要是源码和一个样本索引。

验法:`node -e 'const p=require("./package.json"); console.log(JSON.stringify(p.dependencies), ...)'`,以及 `npm pack --dry-run` 看文件清单。

## 三、我们的服务:只存公开数据

索引里的每一条都来自公开来源:MCP 官方注册表、npm、PyPI、公开的 GitHub 仓库。我们不接收、也不存储客户上传的任何内容——服务是只读的,没有账号、没有表单、没有写入接口。

**访问日志**:Caddy 默认把访问日志写到 journald(含 IP 与 User-Agent),这是运维和排查故障需要的。它不用于广告、不做画像、不与任何第三方共享。

需要你定:保留多少天。我建议 7 天。设置方式:

```sh
# /etc/systemd/journald.conf.d/agentgate.conf
[Journal]
MaxRetentionSec=7day
SystemMaxUse=200M
```

## 四、`refresh`:会联网,但只读公开源,不回传你

`agentgate refresh` 和采集脚本会访问:MCP 官方注册表、npm registry、PyPI、GitHub。它做的是"下载公开信息",**不会把这些请求与你的身份关联,也不发送任何扫描结果**。

如果设置了 `GITHUB_TOKEN`,它只用于提高 GitHub 的速率限制,请不要使用有写入权限的令牌。

## 五、站点:不收集

产品站(落地页、价格页、自己试页、证据索引)是静态页面:

- 没有 cookie,没有统计脚本,没有第三方字体或 CDN;
- 没有账号、没有表单、没有输入框会提交到服务器(索引页的搜索完全在浏览器里跑);
- 唯一的外部链接是我们自己的 GitHub 仓库。

## 六、我们不做什么

- 不卖、不共享任何数据;
- 不把扫描结果与你的身份绑定;
- 不在你没有主动运行的情况下扫描任何东西——扫描都是你或你给的自动化触发的。
