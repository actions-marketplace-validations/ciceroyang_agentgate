# 如果大陆服务器没有可用备案：Plan B

*备案不是技术问题，是准入问题。这一页是为了不把部署卡死在第一步。*

## 判断

在中国大陆的机器上，用域名通过 80/443 提供网页服务需要 ICP 备案，阿里云会拦截未备案的解析。**这一点不能绕过，也不应该绕过。** 所以要先回答一个问题：这台机器在哪、这个域名有没有可用备案。

| 情况 | 能否用 80/443 | 方案 |
| --- | --- | --- |
| 大陆机器 + 已有有效备案（绑这台机器） | 可以 | 直接走 `deployment-runbook.md` |
| 大陆机器 + 没有备案 | 不可以 | 走下面的 B1 或 B2 |
| 香港 / 海外机器 | 可以（无需 ICP） | 直接部署，作为公网入口 |

## B1：公网入口放香港/海外，大陆机器留在内网（推荐）

- 公网 demo 与控制台部署在一台香港或海外的小机器上（2 核 4G 起即可，本项目对算力要求低）；
- 大陆机器保留给内部使用，或者干脆先不用；
- 域名 `app.智量.com`、`api.智量.com` 指向香港机器；
- 主域 `智量.com` 可以继续指向它现在服务的那个站点，不动它。

**代价**：大陆访问香港有几十毫秒延迟，对静态页面和 API 无所谓；合规上，面向大陆用户的网站理论上仍应备案，所以**如果目标是大陆企业客户，最终还是要走备案**，B1 只是让你今天就能开始找设计伙伴，而不是等一个月。

## B2：大陆机器只对内，用非标端口

- 服务监听 `:8080` 或其它非标端口，安全组只对你自己的 IP 开放；
- 用于自测与内部演示，不对外公布；
- 找设计伙伴时用截图与报告，而不是网址。

**代价**：不能"发一条链接给人试"，转化率会低很多。这是最不推荐的选项，但比停滞好。

## B3：现在就去办备案

- 大陆备案通常需要 1–4 周（含管局审核）；
- 需要主体资格（个人或公司）与大陆服务器；
- **建议并行**：先用 B1 上线，同时启动备案，办完再迁回大陆机器。

## 需要确认回答的

1. 服务器在哪个地域？（阿里云控制台能看到：华北/华东/华南 = 大陆；香港 = 境外）
2. 现在 `智量.com` 是否有有效备案？备案号是多少？备案是否绑在这台机器上？
3. 你倾向哪条路？我的建议是 **B1 + 并行办 B3**。
